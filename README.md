# Каталог курсов — тестовое задание

Интерактивный каталог курсов с фильтрацией по категориям, поиском и адаптивной вёрсткой.
Выполнено на **ванильном TypeScript + SCSS** без использования фреймворков и библиотек.

## 📋 О проекте

Одностраничный каталог курсов с карточками (сейчас 17 шт., для соответствия макету; можно любое количество — хранятся в файле `data.ts`).

Пользователь может:

- Фильтровать курсы по категориям
- Искать по названию
- Подгружать карточки кнопкой "Load more"
- Смотреть корректное отображение на любом устройстве

## 🛠️ Технологии

- **TypeScript** — типизация данных и событий
- **SCSS** — стили, CSS-переменные
- **Vite** — сборка, разработка, деплой
- **БЭМ** — именование классов

## 📂 Структура проекта

```plaintext
src/
├── scripts/
│   ├── data.ts          # данные карточек и типы
│   ├── filters.ts       # рендер фильтров + логика фильтрации
│   ├── render.ts        # рендер карточек (DocumentFragment + template)
│   ├── update.ts        # логика обновления интерфейса
│   └── upload.ts        # управление кнопкой Load more
├── styles/
│   ├── common/          # переменные, шрифты, глобальные стили
│   └── blocks/          # стили блоков (БЭМ)
├── main.ts              # точка входа
└── style.scss           # импорт всех стилей


## 🧠 Особенности реализации

- **DataFirst** — все фильтры и карточки генерируются из массива данных (`data.ts`)
- **DocumentFragment + `<template>`** — производительный рендер без перепарсивания строк
- **Умные счётчики** — числа на фильтрах пересчитываются под текущий поиск
- **Одна функция фильтра** — комбинирует категорию и поиск
- **Обработчики через делегирование** — один слушатель на весь блок фильтров
- **Пагинация** — сначала 9 карточек, затем подгрузка по 3 (до 17 / общего количества)
- **Анимации** — плавное появление карточек, hover-эффекты
